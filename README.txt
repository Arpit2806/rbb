HOW TO RUN RAGINI'S BIRTHDAY DASHBOARD
========================================

1. Make sure you have Python installed.
2. Install Streamlit (one-time setup):
   pip install streamlit

3. Keep the folder structure as-is:
   ragini_birthday_dashboard/
     app.py
     assets/
       ragini_1.jpg
       ragini_2.jpg

4. Open a terminal in this folder and run:
   streamlit run app.py

5. It'll open in your browser automatically (usually http://localhost:8501).
   Share your screen or your local network link with her, hand her your
   laptop, or just enjoy it yourself before she sees it. 🎂

Tip: click the "Release the balloons" and "Random Ragini Fact" buttons —
they're interactive and worth showing off.
